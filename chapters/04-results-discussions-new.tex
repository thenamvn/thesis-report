\subsection{Online Anti-Cheat System}
To maintain academic integrity during remote assessments, the system implements a lightweight, browser-based anti-cheat mechanism. As demonstrated in Figure \ref{fig:anticheat-monitor}, the "Security Mode" is activated at the top of the assessment interface, continuously tracking user interactions.

When the system detects prohibited actions such as tab switching or window minimization, it immediately triggers a "Violation Warning" (Figure \ref{fig:anticheat-warning}). This alert interrupts the exam flow, records the incident count, and warns the user that exceeding the violation threshold (e.g., 5 attempts) will result in automatic termination of the session.

\section{System Evaluation and Discussions}
\label{sec:empirical-eval}

Beyond verifying functional correctness, the platform underwent architectural evaluation through technical load testing and qualitative UI/UX assessment to substantiate the system's effectiveness and address the research questions.

\subsection{User Engagement and UI/UX Assessment}
To address RQ1 regarding usability and engagement, the platform was evaluated based on interaction design principles and qualitative feedback during testing. Compared to standard, static form-like quiz interfaces, TEKUTOKO's gamified approach introduces a more dynamic assessment environment. Visual feedback mechanisms, such as the Real-time Quiz Lobby, live leaderboard, and digital voucher systems, directly contribute to the motivational impact on users. The modern interface and intuitive workflow ensure that both educators and students can focus on the learning activities without being hindered by steep learning curves.

\subsection{System Performance and Scalability}
To answer RQ4 regarding the architectural resilience, server performance was evaluated using \texttt{k6}, an open-source load testing tool. The environment was configured to simulate a sudden surge of students accessing the \texttt{/api/discovery/rooms} endpoint concurrently.
\begin{itemize}
    \item \textbf{Peak Throughput:} The backend consistently sustained an average of \textbf{280 Requests Per Second (RPS)}.
    \item \textbf{Latency:} Even at 100 concurrent Virtual Users (VUs), the average response time remained under \textbf{300ms}.
    \item \textbf{Stability:} The test concluded with a \textbf{0\% error rate} (no 5xx HTTP responses).
\end{itemize}
These metrics empirically validate the decision to utilize a stateless Node.js architecture decoupled from the heavy Python processing microservice.

\subsection{Viability of the Online-to-Offline (O2O) Model}
The implementation of the O2O reward system introduces a new dimension to standard EdTech platforms. The practical viability of this model can be mapped directly to university ecosystems. For example, during a University Club Orientation event:
\begin{enumerate}
    \item \textbf{Online Phase:} A club hosts a gamified general knowledge quiz on TEKUTOKO. The top 5 performers automatically receive a unique QR-coded voucher in their digital wallet.
    \item \textbf{Offline Phase (Conversion):} The winners physically navigate to the club's booth on campus. The club administrator uses the Host Dashboard to scan the QR code via smartphone, verifying its authenticity through the backend API, and physically hands over a piece of merchandise or a free drink.
\end{enumerate}
This scenario addresses the "O2O Gap" discussed in Chapter 1, proving that TEKUTOKO's digital-to-physical tracking logic is fully capable of converting online academic engagement into tangible real-world interactions.
